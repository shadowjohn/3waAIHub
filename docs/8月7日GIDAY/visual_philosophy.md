# 視覺哲學：主權算力網格 Sovereign Compute Mesh

整份作品以「把分散的 GPU 變成一張可治理的企業網格」為核心，並把 GIS 集團 I²C+S 的精神延伸到算力：Integration 整合主機與服務、Interoperability 讓節點協作、Communication 讓狀態與用量被看見、Sharing 讓多餘算力創造更多價值。畫面不是炫技式的 AI 霓虹，而是一個能被看懂的治理平面：節點有位置、路由有方向、容量有尺度、權限有邊界。

主色是近黑石墨與深海藍，代表地端、可靠與主權；青藍用來表示正常流動的 API 與節點連線，螢光綠只標記可用、成功與可累積的企業能力，紅橙則專用於風險、壅塞與浪費。顏色不是裝飾，而是固定語義，從 Cluster、VRAM 到用量治理保持一致。

構圖採用「大圖、一句話、一個證據」的節奏。照片與實機畫面負責建立真實感；原生向量圖表負責說明容量、路由、角色與投資循環。文字盡量短，數字與流程盡量大，避免把後台畫面縮成看不清楚的拼貼，也避免用過多小卡片消耗注意力。

視覺母題是三個算力節點向一個統一入口匯聚，再由帳號、Token、Mode 與紀錄形成可追蹤的服務鏈。線條帶有 GIS 網格與拓樸感，但始終服務於閱讀方向；不使用沒有意義的光點、粒子或假儀表板。

字體以 Noto Sans CJK TC 承載中文，Tektur 僅用於英文標記、數字與頁碼，形成工程感但不犧牲可讀性。所有重要文字以會場投影為基準，最低保持可遠距閱讀的尺寸；來源、快照日期與估算 caveat 放在頁尾，不與主張爭奪視線。

作品最終要傳達的情緒不是「未來也許可以」，而是「基礎已經存在，現在應該把它變成制度」。最後一頁回到集團名言的算力版本：一台強的電腦也走不了很遠；但一群被治理、能協作的電腦，可以走得很遠。下一台 AI 主機不再是孤島；買到的是 GPU，累積的是企業能力。
