# 紙電劇場

空間像一冊會呼吸的立體紙書：薄頁、摺線、機械鉸鏈與遠近層次共同形成舞台。形體以精準的剪影和柔和的紙雕厚度組成，讓每個物件看似可以被手指翻起、轉動或重新接線。畫面必須以極少文字成立，意義先由距離、朝向、遮擋與光路傳達，再由短句輕輕定錨。

色彩取自舊紙、皮革、石墨與氧化金屬，亮藍像微弱但持續的電流，橘紅只在熱、摩擦與運算壓力出現。材質差異要經過精密校準：紙纖維保持克制，陰影具有實際折頁方向，金屬不浮誇發亮。整體必須像頂尖工藝師經過無數次打樣才留下的結果，沒有任意漸層，也沒有無意義的裝飾光點。

節奏來自翻頁與揭露。大物件慢慢出現，小標記像旅行圖上的座標逐步累積；一個場景只保留一個視覺動詞，例如打開、堆疊、排隊、輸送或連接。每一頁都以大膽留白控制呼吸，下一頁則沿用前一頁的一條線、一個角度或一個道具，形成經過深思熟慮、近乎舞台機關般的連續運動。

構圖在溫暖敘事與工程紀律之間維持張力。人物以成熟的剪影與姿態表達，不靠誇張表情；技術物件保留真實名稱、端口、佇列與節點關係，但被轉譯成可被觀看的場所。每條連線都必須有起點與終點，每個層級都經過痛苦而細密的對齊，呈現大師級的空間控制，而不是把資訊卡片貼在背景上。

工藝是整個系統的證據。字體、摺痕、線寬、光源與頁邊都必須像耗費無數工時反覆修整；即使是最小的頁碼，也要與全局秩序精準咬合。最終作品應像一件被珍藏多年的機械圖譜：初看有故事，細看有系統，再看仍能發現嚴密安排的細節，讓深厚專業以安靜而不可否認的方式存在。
